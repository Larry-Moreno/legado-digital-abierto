GitHub

GitHub trabaja con personas autorizadas para decidir qué ocurre con el contenido de una cuenta, incluido transferir repositorios públicos o cancelar cobros.

Cobertura: Política global de GitHub; pueden aplicar requisitos legales locales.

Transferir repositorios públicosCancelar facturaciónOtra solicitud autorizada

Quién puede solicitarlo

  • Familiar más cercano.
  • Sucesor previamente designado en GitHub.
  • Otra persona autorizada, como colaborador o socio comercial, según el caso.

Información o documentos indicados

  • Nombre y datos de contacto del solicitante.
  • Nombre y usuario de GitHub de la persona fallecida.
  • Relación con el titular y acción solicitada.
  • Posible identificación, certificado de defunción y prueba de autorización si GitHub los pide.

Ruta recomendada

  1. Abre el portal de Soporte de GitHub desde la política oficial.
  2. Describe tu relación y la acción concreta que solicitas.
  3. Espera la petición de documentos adicionales antes de enviar material sensible.

Advertencias

  • GitHub decide qué información adicional necesita después de recibir la solicitud.
  • No envíes documentos a repositorios, issues ni direcciones no indicadas por Soporte.
  • Los repositorios públicos ya pueden clonarse sin solicitar acceso a la cuenta.

Fuente oficial
