LinkedIn

LinkedIn permite informar un fallecimiento para conmemorar un perfil. Solo una persona autorizada, con documentación legal aceptada, puede solicitar el cierre.

Cobertura: Proceso general de LinkedIn; la ayuda enlazada está disponible en español.

Convertir en conmemorativaCerrar cuenta

Quién puede solicitarlo

  • Cualquier persona con información suficiente puede informar el fallecimiento para conmemorar.
  • Representante autorizado por tribunal para solicitar el cierre.

Información o documentos indicados

  • Nombre completo y URL del perfil.
  • Relación, correo del miembro, fecha de fallecimiento y enlace a obituario o noticia.
  • Para cierre: documento judicial que designe al solicitante como representante autorizado.

Ruta recomendada

  1. Elige si vas a informar para conmemorar o, con autoridad legal, solicitar cierre.
  2. Reúne únicamente los datos y documentos que LinkedIn enumera como aceptados.
  3. Usa el enlace de contacto incluido en la ayuda oficial.

Advertencias

  • LinkedIn no revela nombres de usuario ni contraseñas.
  • Testamentos, poderes y documentos de identidad por sí solos pueden no ser aceptados para el cierre.
  • La cuenta conmemorativa queda bloqueada para iniciar sesión.
