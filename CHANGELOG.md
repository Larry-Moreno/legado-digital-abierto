# Historial de cambios

## 1.1.0 - 2026-10-02

- Revalidación manual de las diez fuentes oficiales y actualización de la URL canónica de PayPal Estados Unidos.
- Validación completa del conjunto contra JSON Schema con Ajv.
- Documentación pública navegable y fichas enlazables por plataforma.
- Metadatos de buscador y redes, sitemap, robots y controles defensivos en HTML.
- Navegación móvil visible, anclas corregidas y mejor uso del espacio para un resultado único.
- Canal privado de seguridad, plantillas de issues y pull requests y documentación alineada con el estado real.
- Build publicable en `docs/`, la misma carpeta servida por GitHub Pages.

## 1.0.0 - 2026-09-07

- Primera V1 local y publicación inicial en GitHub Pages.
- Diez plataformas con fuentes oficiales verificadas.
- Búsqueda, filtro por acción y lista imprimible local.
- Pruebas de datos, seguridad estática, accesibilidad básica y enlaces.
- Documentación de metodología, contribución, privacidad, seguridad y licencias.
