# Código de conducta

## Compromiso

Este proyecto busca una colaboración respetuosa, segura y útil para personas de cualquier experiencia, identidad o procedencia. No se toleran acoso, amenazas, discriminación, publicación de datos personales ni uso de casos reales para exponer a una familia.

## Conducta esperada

- Criticar ideas y cambios, no personas.
- Aportar fuentes verificables y explicar límites o incertidumbre.
- Proteger la privacidad de personas fallecidas, familiares y solicitantes.
- Retirar contenido sensible cuando se detecte.
- Respetar decisiones de moderación orientadas a seguridad, exactitud y sostenibilidad.

## Aplicación

Los mantenedores pueden editar, ocultar o cerrar contribuciones que incumplan estas reglas y restringir a participantes que mantengan una conducta dañina.

Para abuso ocurrido en GitHub usa los mecanismos de [reporte de contenido de GitHub](https://support.github.com/contact/report-abuse). Para vulnerabilidades usa exclusivamente el reporte privado indicado en `SECURITY.md`.

## Alcance

Aplica al repositorio, issues, pull requests y espacios públicos donde una persona represente al proyecto.
